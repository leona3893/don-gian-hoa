Gõ npm test thì báo "unknown command test"

PS D:\thu-nghiem\don-gian-hoa\tests> npm test
error: unknown command 'test'

Sửa

cd D:\thu-nghiem\don-gian-hoa
npm install
npx playwright install chromium
npm test

Vì sao & nhớ gì

  1. Nhìn dòng nhắc trước khi gõ — Dòng PS D:\...> cho biết bạn đang đứng ở đâu. Mọi lệnh npm/npx phải gõ ở gốc dự án — chỗ có package.json.
  2. Clone mới = cài lại thư viện — node_modules không nằm trong Git (xem .gitignore), nên mỗi bản clone phải tự npm install. Thiếu nó, máy gọi nhầm một playwright khác cài sẵn — bản đó không có lệnh test.
  3. cd .. lùi ra, cd tên-folder đi vào — Muốn sang folder ngang hàng thì lùi ra trước rồi mới đi vào.

Liên quan: Git · Playwright · Test Runner
