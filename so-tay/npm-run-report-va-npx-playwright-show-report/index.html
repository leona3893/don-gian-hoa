npm run report và npx playwright show-report khác nhau gì?

Hai lệnh này đều mở báo cáo test. Gõ cái nào cũng được, hay có khác gì?

Gõ thử

npm run report
npx playwright show-report

Vì sao & nhớ gì

  1. Hai lệnh làm cùng một việc — Mở package.json, mục scripts có dòng "report": "playwright show-report". npm run report chỉ là phím tắt: npm tra bảng đó rồi chạy đúng lệnh bên phải hộ bạn.
  2. npm = quản kho + bấm nút có sẵn — npm install tải thư viện về node_modules; npm run <tên> bấm nút đã đặt tên trong scripts. Riêng npm test và npm start được gõ tắt, không cần chữ run.
  3. npx = chạy thẳng một chương trình trong kho — Khi cần thêm tuỳ chọn mà nút không có — chạy 1 file, bật --headed — thì dùng npx playwright test …. Việc lặp lại hàng ngày thì dùng nút npm run để cả team gõ giống nhau.
