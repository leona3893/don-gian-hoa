npm và npx khác nhau thế nào?

Trả lời ngắnnpm là người quản kho: tải thư viện về và bấm những nút đã đặt tên sẵn. npx là chạy thẳng một chương trình trong kho đó, tự thêm tuỳ chọn tuỳ ý.

Bảng so sánh

npmnpx
Việc chínhTải thư viện (npm install) và chạy nút có tên trong package.json (npm run …)Chạy trực tiếp một chương trình nằm trong node_modules
Lệnh đi sau nóTên nút do dự án đặt: build, test, reportTên chương trình thật: playwright, serve
Thêm tuỳ chọnKhông tiện — nút ghi sao chạy vậyThoải mái: --headed, --debug, một file cụ thể
Nếu chưa càiBáo lỗi hoặc gọi nhầm bản khác trên máyTự tải tạm về chạy rồi vứt
Ví dụ cùng một việcnpm run reportnpx playwright show-report

💡 Cách nhớ

npm = bấm nút có sẵn. npx = cầm dụng cụ lên dùng trực tiếp. Nút thì ai bấm cũng giống nhau; cầm trực tiếp thì tự chỉnh được.

Chọn cái nào?

  • Nếu Việc lặp lại hàng ngày, dự án đã đặt tên sẵn (build, test)→ npm run — ngắn và cả team gõ giống nhau
  • Nếu Cần chạy 1 file test hoặc bật --headed để nhìn trình duyệt→ npx playwright test … — nút không có tuỳ chọn này
  • Nếu Muốn thử một công cụ một lần→ npx — không phải cài toàn máy

⚠ Bẫy thường gặp

npx ở một folder chưa npm install sẽ âm thầm tải bản mới nhất về chạy — có thể khác phiên bản dự án đang dùng. Test đỏ mà lý do chẳng liên quan gì tới code. Luôn npm install trước, rồi mới npx.

Câu hỏi hay gặp

npm run report và npx playwright show-report có khác gì không?
Không. Mở package.json sẽ thấy dòng "report": "playwright show-report" — npm run report chỉ là phím tắt tra bảng rồi chạy đúng lệnh đó.
Vì sao npm test không cần chữ run?
test và start là hai tên đặc biệt npm cho gõ tắt. Các tên khác như build, report vẫn phải có run.
Có cần cài npx riêng không?
Không. npx đi kèm npm từ phiên bản 5.2, cài Node.js là có cả hai.
