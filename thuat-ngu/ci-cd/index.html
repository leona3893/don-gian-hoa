🔄 CI/CD là gì?

Máy tự chạy test và phát hành mỗi khi có code mới.

CI/CD là quy trình tự động: mỗi lần đẩy code lên, hệ thống tự build, chạy test, và nếu đạt thì đưa luôn lên môi trường thật.

Nói theo đời thường:
Như băng chuyền nhà máy: hàng vừa lắp xong tự trôi qua trạm kiểm tra, đạt thì đi tiếp, lỗi thì gạt ra ngay tại chỗ.
