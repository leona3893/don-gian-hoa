📜 Test Script là gì?

Đoạn code thực hiện bài kiểm tra.

1
Hiểu nó là gì

Test Script là mã nguồn viết ra để máy tự chạy một test case: mở trang, điền dữ liệu, bấm nút rồi so kết quả.

Nói theo đời thường:
Như kịch bản quay phim ghi rõ từng động tác: diễn viên, ở đây là máy, cứ theo đó mà làm chứ không tự nghĩ thêm.

⚠ Chỗ ẩn dụ này hỏng

Kịch bản phim viết cho diễn viên biết suy đoán. Máy thì không suy đoán gì cả.

Bạn ghi “bấm nút Đăng nhập” thì máy hỏi lại: nút nào, nếu có hai nút cùng chữ đó thì sao, nếu nút chưa hiện thì đợi bao lâu, nếu nút bị che thì tính là bấm được không. Mọi thứ bạn coi là hiển nhiên đều phải viết ra.

2
Code trông thế nào
// Ca test bằng tiếng Việt → thành code
await page.goto('/dang-nhap')
await page.getByLabel('Email').fill('na@vd.com')
await page.getByLabel('Mật khẩu').fill('matkhausai')
await page.getByRole('button', { name: 'Đăng nhập' }).click()
await expect(page.getByRole('alert')).toContainText('Sai email hoặc mật khẩu')

Từng dòng ứng đúng một bước trong ca test viết tay ở trên.

3
Khi nào bạn dùng nó

✓ Dùng khi

  • Ca test đã ổn định, không đổi mỗi tuần
  • Cần chạy lại thường xuyên
  • Muốn máy chạy lúc mình đang ngủ

✗ Đừng dùng khi

  • Còn đang dò xem tính năng chạy thế nào
  • Ca test viết tay còn chưa rõ “đúng” là gì
Chưa cần biết: gom code dùng chung, fixture, hook trước/sau, tham số hoá ca test.
Để dành tới Mốc 2 — Tự viết được cái đầu tiên: Bạn viết được một test mở trang, bấm nút, kiểm tra chữ hiện ra — và nó chạy xanh trên máy bạn.
Dấu hiệu bạn đã cần học nó: Khi bạn sửa một cái nút mà phải mở 12 file test ra sửa cùng một dòng.
4
Đi đâu tiếp
  • LocatorPhần khó nhất của script: chỉ đúng phần tử cần bấm.
  • AssertionDòng cuối quyết định test đỗ hay trượt.
  • Page Object ModelCách dọn script khi nó bắt đầu lặp lại.

🧪 Thử 2 phút, không cần cài gì

F12 → Console, trên một trang có ô tìm kiếm: 
document.querySelector('input').value = 'áo thun'
Bạn vừa viết dòng script đầu tiên: điền dữ liệu vào ô mà không đụng bàn phím.
