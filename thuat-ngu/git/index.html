🕰️ Git là gì?

Cỗ máy thời gian cho mã nguồn.

1
Hiểu nó là gì

Git lưu các mốc thay đổi của dự án và giúp nhiều người làm cùng nhau mà không mất công việc.

Nói theo đời thường:
Như Google Docs có lịch sử chỉnh sửa, nhưng mạnh hơn và dành cho việc làm phần mềm.

⚠ Chỗ ẩn dụ này hỏng

Cỗ máy thời gian — nhưng Git không lưu “thay đổi”, nó lưu toàn bộ ảnh chụp dự án ở mỗi lần commit.

Hiểu sai chỗ này là nguồn gốc của mọi nỗi sợ Git. Khi biết mỗi commit là một ảnh chụp đầy đủ và gần như không bao giờ mất, bạn sẽ thôi sợ thao tác sai — vì hầu hết thứ bạn tưởng đã mất vẫn nằm trong git reflog.

2
Code trông thế nào
git status            # đang có gì thay đổi
git add .             # chọn thứ muốn lưu
git commit -m "sửa lỗi tính tiền"   # chụp một ảnh
git push              # đẩy lên chỗ chung

git log --oneline     # xem lại các mốc đã chụp

Năm lệnh này đủ dùng cho 90% công việc hàng ngày.

3
Khi nào bạn dùng nó

✓ Dùng khi

  • Nhiều người cùng sửa một dự án
  • Cần quay lại phiên bản cũ khi hỏng
  • Muốn biết ai đổi dòng nào lúc nào

✗ Đừng dùng khi

  • File nhị phân lớn như video (Git không hợp)
  • Lưu mật khẩu và khoá bí mật (commit lên là lộ vĩnh viễn)
Chưa cần biết: rebase, cherry-pick, giải quyết xung đột phức tạp, mô hình nhánh.
Để dành tới Mốc 3 — Tự dựng được: Bạn tự đưa được một trang lên mạng, và biết phải sờ vào đâu khi nó không lên.
Dấu hiệu bạn đã cần học nó: Khi bạn cần gộp nhánh của mình với nhánh chung mà hai bên cùng sửa một file.
4
Đi đâu tiếp
  • DeployBước sau khi code đã vào Git.
  • CI/CDThứ tự động chạy mỗi khi bạn push.
  • BugGit giúp tìm ra commit nào làm sinh bug.

🧪 Thử 2 phút, không cần cài gì

Vào một repo bất kỳ trên GitHub, bấm vào một file rồi chọn History. Bạn đang xem cỗ máy thời gian của người khác — mỗi dòng là một ảnh chụp.
