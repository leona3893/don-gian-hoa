🍽️ API là gì?

Người phục vụ giúp hai phần mềm nói chuyện.

API là cánh cửa có quy tắc để một ứng dụng yêu cầu dữ liệu hoặc việc gì đó từ ứng dụng khác.

Nói theo đời thường:
Hãy hình dung bạn không vào bếp tự nấu: bạn gọi món với người phục vụ. Họ chuyển đúng yêu cầu vào bếp và mang kết quả ra.
