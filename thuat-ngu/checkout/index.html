🚪 Checkout là gì?

Bước sang nhánh khác — cả folder đổi theo.

1
Hiểu nó là gì

Checkout là lệnh chuyển sang một nhánh (hoặc một commit) khác. Sau khi checkout, mọi file trong folder dự án biến thành đúng trạng thái của nhánh đó.

Nói theo đời thường:
Như bước từ phòng này sang phòng kia trong cùng căn nhà: đồ đạc bạn thấy đổi hết, nhưng phòng cũ vẫn còn nguyên, quay lại lúc nào cũng được.

⚠ Chỗ ẩn dụ này hỏng

Bước sang phòng khác — nhưng đồ đang cầm trên tay (file sửa dở, chưa commit) đi theo bạn sang phòng mới.

Đây vừa là điểm hay vừa là bẫy. Hay: lỡ sửa trên main mà chưa commit, gõ git checkout -b nhanh-moi là thay đổi được mang sang nhánh mới, main sạch trở lại. Bẫy: bạn tưởng đã “để lại” thay đổi ở nhánh cũ, hoá ra không. Và nếu thay đổi dở dang đụng đúng file mà nhánh đích cũng khác, Git từ chối checkout để không làm mất công của bạn — lúc đó commit trước hoặc git stash cất tạm.

2
Code trông thế nào
git checkout main               # về nhánh chính
git checkout -b thu-nghiem/ci-do # tạo nhánh mới VÀ chuyển sang luôn (-b = branch)
git checkout thu-nghiem/ci-do    # chuyển sang nhánh đã có

git branch                       # đang đứng ở đâu? dấu * là nhánh hiện tại
  main
* thu-nghiem/ci-do

git checkout -- tests/a.spec.js  # nghĩa KHÁC: huỷ sửa đổi của 1 file, về bản đã commit (mất thật)

Hai lệnh checkout và branch đi cặp: branch để nhìn, checkout để bước sang.

3
Khi nào bạn dùng nó

✓ Dùng khi

  • Bắt đầu một việc mới: checkout -b từ main mới nhất
  • Quay về main để lấy code mới hoặc tạo nhánh khác
  • Lỡ sửa trên main chưa commit — checkout -b mang sang nhánh riêng

✗ Đừng dùng khi

  • checkout -- . khi chưa chắc muốn vứt toàn bộ sửa đổi — không có undo
  • Checkout sang nhánh khác giữa chừng khi đang có file sửa dở mà chưa hiểu nó sẽ đi theo
Chưa cần biết: git switch / git restore (hai lệnh mới tách vai trò của checkout), detached HEAD, checkout một commit cũ.
Để dành tới Mốc 3 — Tự dựng được: Bạn tự đưa được một trang lên mạng, và biết phải sờ vào đâu khi nó không lên.
Dấu hiệu bạn đã cần học nó: Khi bạn thấy dòng “You are in detached HEAD state” và không hiểu mình đang ở đâu.
4
Đi đâu tiếp
  • BranchThứ mà checkout bước sang.
  • CommitCất đồ trước khi đổi phòng thì không sợ mang nhầm.
  • Pull RequestNhánh vừa checkout -b rồi làm gì tiếp.

🧪 Thử 2 phút, không cần cài gì

Trong một repo bất kỳ: git branch xem mình đang ở đâu, git checkout -b thu, git branch lại — dấu * đã nhảy. Rồi git checkout main và git branch -d thu để dọn. Mất 1 phút, và từ giờ bạn không còn sợ lệnh này.
