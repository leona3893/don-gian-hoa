🔌 API Testing là gì?

Test thẳng vào phần lõi, bỏ qua giao diện.

API Testing gửi request trực tiếp tới backend rồi kiểm tra response, nên chạy nhanh và ổn định hơn hẳn so với test qua giao diện.

Nói theo đời thường:
Thay vì đi vòng ra quầy gọi món, mình hỏi thẳng nhà bếp xem có làm đúng đơn không: nhanh hơn và ít khâu hỏng vặt.
