🎯 npx là gì?

Chạy đúng chương trình nằm trong kho của dự án.

1
Hiểu nó là gì

npx tìm chương trình trong node_modules của dự án rồi chạy nó — không cần cài toàn máy, không sợ gọi nhầm một bản khác đang có sẵn trên máy.

Nói theo đời thường:
Trong nhà có nhiều tua vít cũ mới lẫn lộn. npx là người giúp việc lấy đúng cái tua vít dự án này đã mua, không vớ nhầm cái của hàng xóm.

⚠ Chỗ ẩn dụ này hỏng

Lấy đúng cái tua vít của dự án — nhưng nếu trong tủ chưa có, npx sẽ ra tiệm tải tạm một cái về dùng rồi vứt.

Tiện khi muốn thử nhanh một công cụ. Nhưng cũng là bẫy: bạn gõ npx playwright test ở một folder chưa npm install, npx tải tạm bản mới nhất về — có thể khác phiên bản dự án đang dùng, và test đỏ vì lý do chẳng liên quan gì tới code.

2
Code trông thế nào
npx playwright test --headed          # chạy bản playwright trong node_modules, thêm tuỳ chọn
npx playwright test tests/so-tay.spec.js   # chỉ chạy một file
npx playwright show-report           # y hệt npm run report, chỉ là gõ trực tiếp
npx serve .                          # bật web tĩnh ở folder hiện tại

Cùng một chương trình: npm run bấm nút có sẵn, npx gọi thẳng và tự thêm tuỳ chọn.

3
Khi nào bạn dùng nó

✓ Dùng khi

  • Cần thêm tuỳ chọn mà nút trong scripts không có (--headed, --debug, một file cụ thể)
  • Chạy công cụ một lần, không đáng đặt thành nút (codegen, serve)
  • Không muốn cài công cụ toàn máy chỉ để thử

✗ Đừng dùng khi

  • Việc cả team làm hàng ngày — đặt thành nút npm run để ai cũng gõ giống nhau
  • Chạy npx ở folder chưa npm install rồi tin vào kết quả
Chưa cần biết: npx với phiên bản cụ thể (npx playwright@1.50), cờ --no-install, npm exec.
Để dành tới Mốc 3 — Tự dựng được: Bạn tự đưa được một trang lên mạng, và biết phải sờ vào đâu khi nó không lên.
Dấu hiệu bạn đã cần học nó: Khi CI và máy bạn cho kết quả khác nhau dù cùng một lệnh npx.
4
Đi đâu tiếp
  • npmNgười quản kho — npx chỉ lấy đồ trong kho đó.
  • Test RunnerThứ npx playwright test thực sự gọi lên.
  • HeadlessTuỳ chọn --headed bật/tắt cái gì.

🧪 Thử 2 phút, không cần cài gì

Ở gốc một dự án đã npm install, gõ npx playwright --version. Rồi vào một folder trống bất kỳ, gõ lại đúng lệnh đó. Lần thứ hai npx phải ra tiệm tải — bạn vừa thấy tận mắt sự khác nhau giữa “có trong tủ” và “chưa có”.
