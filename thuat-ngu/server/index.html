🏢 Server là gì?

Nơi luôn trực để trả lời yêu cầu từ người dùng.

1
Hiểu nó là gì

Server là máy tính hoặc chương trình cung cấp dữ liệu, xử lý yêu cầu và gửi kết quả về cho thiết bị của bạn.

Nói theo đời thường:
Giống quầy bếp luôn mở: bạn đặt món từ điện thoại, quầy bếp nhận đơn, làm món rồi gửi lại.

⚠ Chỗ ẩn dụ này hỏng

Quầy bếp luôn mở — nhưng “server” ngày nay thường không phải một cái máy nào cả.

Nó có thể là hàng chục máy ảo tự sinh ra tự mất đi theo lượng khách, hoặc một hàm chạy đúng 200 mili giây rồi biến mất (serverless). Hình dung “một cái máy đứng đâu đó” giúp bạn bắt đầu, nhưng sẽ vướng khi nghe tới auto-scaling hay container.

2
Code trông thế nào
// Một server tối giản bằng Node.js
import http from 'http'

http.createServer((req, res) => {
  res.end('Chào bạn')
}).listen(3000)

// Mở trình duyệt vào localhost:3000 là thấy

Bốn dòng. Server thực chất chỉ là một chương trình ngồi chờ và trả lời.

3
Khi nào bạn dùng nó

✓ Dùng khi

  • Cần chỗ chạy code liên tục để phục vụ người dùng
  • Cần nơi giữ dữ liệu chung cho mọi người
  • Xử lý việc nặng mà máy người dùng không kham nổi

✗ Đừng dùng khi

  • Trang tĩnh thuần (dùng hosting tĩnh rẻ hơn nhiều)
  • Việc chỉ chạy một lần rồi thôi
Chưa cần biết: cân bằng tải, container, tự co giãn, serverless.
Để dành tới Mốc 3 — Tự dựng được: Bạn tự đưa được một trang lên mạng, và biết phải sờ vào đâu khi nó không lên.
Dấu hiệu bạn đã cần học nó: Khi trang của bạn sập vào đúng giờ đông người và bạn không biết thêm máy kiểu gì.
4
Đi đâu tiếp
  • CloudCách thuê server mà không phải mua máy.
  • APICách người ngoài nói chuyện với server.
  • DeployCách đưa code lên server.

🧪 Thử 2 phút, không cần cài gì

F12 → Network, tải lại một trang. Cột Time cho biết server mất bao lâu để trả lời bạn. Trên 500ms là người dùng bắt đầu thấy chậm.
