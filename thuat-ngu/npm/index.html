📦 npm là gì?

Kho thư viện kèm người quản kho cho JavaScript.

1
Hiểu nó là gì

npm tải các thư viện dự án cần về máy (npm install) và bấm những “nút” đã đặt tên sẵn trong package.json (npm run build, npm test…).

Nói theo đời thường:
Như đi siêu thị với sổ đi chợ: package.json là danh sách cần mua, npm install đi mua về xếp vào tủ node_modules. Còn npm run là bấm nút có sẵn trên máy giặt — ai bấm cũng ra cùng kết quả.

⚠ Chỗ ẩn dụ này hỏng

Sổ đi chợ — nhưng đồ mua về (node_modules) không đi theo dự án khi bạn clone. Chỉ có sổ đi chợ (package.json) được lưu trong Git.

Vì thế bản clone mới nào cũng phải npm install lại từ đầu. Đây là nguồn của lỗi kinh điển “gõ lệnh mà máy không hiểu”: thư viện chưa được tải về nên lệnh không tồn tại, hoặc máy vớ nhầm một bản khác đang cài sẵn.

2
Code trông thế nào
npm install              # đọc package.json, tải thư viện vào node_modules
npm run build            # bấm "nút" tên build trong mục scripts
npm test                 # viết tắt của npm run test

# Trong package.json, mục scripts chính là bảng tên các nút:
"scripts": {
  "build":  "node build.mjs",
  "test":   "playwright test",
  "report": "playwright show-report"
}

npm run <tên> chỉ là phím tắt: npm tra bảng scripts rồi chạy lệnh bên phải hộ bạn.

3
Khi nào bạn dùng nó

✓ Dùng khi

  • Vừa clone dự án về — chạy npm install trước khi làm gì khác
  • Việc lặp lại hàng ngày mà dự án đã đặt tên sẵn (build, test, report)
  • Muốn cả team gõ cùng một lệnh ra cùng một kết quả

✗ Đừng dùng khi

  • Cần thêm tuỳ chọn mà nút không có sẵn (ví dụ chạy 1 file test) — dùng npx
  • Sửa tay package-lock.json — file này npm tự sinh
Chưa cần biết: workspaces, publish thư viện, semver, npm ci vs npm install.
Để dành tới Mốc 3 — Tự dựng được: Bạn tự đưa được một trang lên mạng, và biết phải sờ vào đâu khi nó không lên.
Dấu hiệu bạn đã cần học nó: Khi CI đỏ vì “lock file lệch với package.json” mà ở máy bạn vẫn xanh.
4
Đi đâu tiếp
  • npxChạy thẳng một chương trình trong kho, không qua nút.
  • GitVì sao node_modules không đi theo khi clone.
  • PlaywrightThư viện test mà npm tải về cho dự án này.

🧪 Thử 2 phút, không cần cài gì

Mở package.json của bất kỳ dự án nào, tìm mục scripts. Mỗi dòng bên trái là một nút bạn bấm được bằng npm run <tên> — bạn vừa đọc được “bảng điều khiển” của dự án đó.
