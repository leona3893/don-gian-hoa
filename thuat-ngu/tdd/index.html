🔴 TDD là gì?

Viết test trước, viết code sau.

TDD yêu cầu viết test cho tính năng chưa có, nhìn nó fail, rồi mới viết vừa đủ code để test pass và dọn lại cho gọn.

Nói theo đời thường:
Như dựng khuôn bánh trước rồi mới đổ bột: khuôn quyết định hình dáng, nên không phải đổ tràn lan rồi ngồi cắt gọt.
