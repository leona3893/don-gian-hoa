📸 Commit là gì?

Một ảnh chụp dự án, kèm lời ghi chú vì sao chụp.

1
Hiểu nó là gì

Commit là một điểm lưu trong Git: toàn bộ dự án ở đúng thời điểm đó, cộng với một câu mô tả bạn đã thay đổi gì.

Nói theo đời thường:
Như chụp ảnh căn phòng sau mỗi lần dọn, rồi ghi chú sau tấm ảnh “đã chuyển bàn ra cửa sổ”. Sau này lật lại là biết phòng từng trông thế nào và vì sao đổi.

⚠ Chỗ ẩn dụ này hỏng

Ảnh chụp căn phòng — nhưng không phải cứ dọn xong là máy tự chụp. Bạn phải chọn thứ gì vào ảnh (git add) rồi mới bấm chụp (git commit).

Đây là chỗ người mới hay vấp: sửa xong 5 file, gõ git commit và Git bảo “không có gì để commit”. Vì chưa add. Bước add tồn tại để bạn có thể chụp một phần thay đổi thôi — ví dụ sửa lỗi và sửa chính tả thành hai commit riêng, sau này dễ tìm.

2
Code trông thế nào
git status                      # đang sửa dở những file nào
git add -A                      # đưa TẤT CẢ thay đổi vào khung hình
git commit -m "Thêm thuật ngữ Docker"   # bấm chụp, kèm ghi chú

git log --oneline -5            # 5 ảnh gần nhất, mỗi dòng một commit
a1b2c3d Thêm thuật ngữ Docker
2595a41 Thêm Playwright test và pipeline CI/CD
599c4b6 Sinh ảnh chia sẻ cho cả 83 trang

Lời commit tốt trả lời câu “commit này làm gì?” — không phải “sửa”, “update”, “fix bug”.

3
Khi nào bạn dùng nó

✓ Dùng khi

  • Vừa xong một việc trọn vẹn: một tính năng nhỏ, một lỗi đã sửa
  • Sắp thử một thứ có thể hỏng — chụp lại trước để có đường lui
  • Cuối buổi làm việc, dù chưa xong hẳn (ghi rõ “đang dở”)

✗ Đừng dùng khi

  • Gom cả tuần làm việc vào một commit khổng lồ — hỏng chỗ nào không lần ra được
  • Commit file chứa mật khẩu, API key — lên rồi là lộ vĩnh viễn dù xoá sau
  • Commit thư mục node_modules hay file build nặng không cần thiết
Chưa cần biết: amend, squash, rebase để viết lại lịch sử, ký commit.
Để dành tới Mốc 3 — Tự dựng được: Bạn tự đưa được một trang lên mạng, và biết phải sờ vào đâu khi nó không lên.
Dấu hiệu bạn đã cần học nó: Khi bạn nhìn lịch sử của mình và thấy 10 commit liên tiếp cùng tên “fix”.
4
Đi đâu tiếp
  • PushCommit mới chỉ nằm trên máy bạn. Đây là bước đưa nó lên.
  • BranchChuỗi commit này đang nằm trên nhánh nào?
  • GitBức tranh lớn mà commit là viên gạch.
