🌿 Branch là gì?

Một bản sao để thử nghiệm, không đụng bản chính.

1
Hiểu nó là gì

Branch là một dòng phát triển riêng: bạn commit thoải mái trên đó, bản chính (thường tên là main) vẫn nguyên vẹn cho tới khi bạn quyết định gộp vào.

Nói theo đời thường:
Như photocopy bản thảo ra để viết nháp. Nháp hỏng thì vứt, không ảnh hưởng bản gốc; nháp hay thì chép ngược lại.

⚠ Chỗ ẩn dụ này hỏng

Photocopy bản thảo ra để viết nháp — nhưng tạo nhánh trong Git không tốn một giây và không copy file nào cả.

Một nhánh chỉ là cái nhãn trỏ vào một commit. Nên đừng tiếc nhánh: tạo mỗi việc một nhánh, làm xong gộp, xoá. Người mới hay làm tất cả trên main vì “tạo nhánh phiền” — thật ra nó là một lệnh, và nó cứu bạn khỏi việc phá bản đang chạy.

2
Code trông thế nào
git switch -c them-nut-danh-gia   # tạo nhánh mới và nhảy sang
# ... sửa, commit thoải mái, main không bị đụng ...

git branch                        # đang có nhánh nào, dấu * là nhánh đang đứng
  main
* them-nut-danh-gia

git switch main                   # quay về bản chính
git branch -d them-nut-danh-gia   # xoá nhánh sau khi đã gộp xong

Đặt tên nhánh theo việc đang làm: them-nut-danh-gia, sua-loi-tim-kiem — không phải test, nhanh2.

3
Khi nào bạn dùng nó

✓ Dùng khi

  • Bắt đầu một tính năng hoặc sửa một lỗi
  • Muốn thử một ý tưởng chưa chắc dùng
  • Nhiều người cùng làm — mỗi người một nhánh, không giẫm chân

✗ Đừng dùng khi

  • Sửa lỗi chính tả một dòng khi làm một mình — commit thẳng main cũng được
  • Để nhánh sống hàng tháng không gộp — càng lâu càng khó gộp
Chưa cần biết: Git Flow, trunk-based, nhánh release/hotfix, bảo vệ nhánh.
Để dành tới Mốc 3 — Tự dựng được: Bạn tự đưa được một trang lên mạng, và biết phải sờ vào đâu khi nó không lên.
Dấu hiệu bạn đã cần học nó: Khi đội bạn có 5 người và ai cũng hỏi “giờ nhánh nào là bản mới nhất?”
4
Đi đâu tiếp
  • Pull RequestCách đưa nhánh trở lại main một cách có kiểm soát.
  • MergeThao tác gộp nhánh về đích.
  • CommitThứ nằm trên nhánh.

🧪 Thử 2 phút, không cần cài gì

Trong dự án của bạn: git switch -c thu-nghiem, sửa lung tung một file, rồi git switch main. Mở file đó ra — nó nguyên vẹn. Nhánh chính là bảo hiểm miễn phí.
