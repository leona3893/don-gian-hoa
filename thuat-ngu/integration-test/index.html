🔗 Integration Test là gì?

Thử xem các phần ghép với nhau có chạy không.

Integration Test kiểm tra nhiều thành phần làm việc chung: code gọi database, gọi API hay đọc file có đúng như kỳ vọng không.

Nói theo đời thường:
Linh kiện nào cũng tốt chưa chắc lắp vào là chạy; đây là lúc cắm điện cả mạch xem có sáng thật không.
